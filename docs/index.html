Loadout TC

A client-side equipment HUD for Fabric 1.21.1. Loadout TC reads Vanilla, Accessories, Trinkets and Curios through one model, draws them with a styleable renderer, and lets other mods add slot sources, effects and ability timers.

What it does#

  • One HUD for every equipment mod; a source that is missing is simply skipped.
  • Slot menu with one tab per source, per-slot ticks, five sort orders and manual ▲ ▼ ordering.
  • Several independent panels on screen, each with its own slots, position and look.
  • Durability, cooldown and ability layers, each with its own style, colour, thickness and text.
  • In-game editor with a live preview; every change is saved automatically.

Install#

  1. Install Fabric Loader and Fabric API for Minecraft 1.21.1.
  2. Install at least one of Accessories, Trinkets or Curios.
  3. Drop loadouttc-1.0.0+1.21.1.jar into .minecraft/mods.
  4. Launch the game and press H.

Curios on Fabric 1.21.1. Curios 9.5.1 is published for NeoForge, so the mod talks to it reflectively and only activates when the API is visible, for example through Sinytra Connector. Without it, the Accessories and Trinkets providers work normally.

Sizes#

Auto keeps a slot at vanilla hotbar size for the current GUI scale. The presets go well beyond it, so a HUD can be much larger than the hotbar:

PresetScaleUse it when
Auto1.00x of the GUI scaleYou want the exact vanilla hotbar size
S0.80xThe HUD should stay out of the way
M1.00xDefault readable size
L1.25xSlightly larger labels and icons
XL1.50xBigger HUD, still compact
2x2.00xBig icons, living-room distance
3x3.00xMaximum preset
Custom0.50 - 3.00xAny value in between

If the HUD would run off screen, it is scaled down just enough to stay visible.

Slots and panels#

  • Slots opens the slot menu: tabs per source, a heading and on/off switch per vanilla group, and All / Checked, Empty, Sort and Check all / Clear in one row.
  • A panel is an independent HUD. Split one off to keep accessories in another corner; merge panels back without losing slots.
  • Any slot no panel claims falls into the rest panel, so a fresh install behaves like a single HUD.

Each layer has its own colour row, thickness 1-4 px, opacity, track, pulse, reverse and text mode. Full durability bars sit at 45% opacity; below 20% they turn red and pulse.

For mod authors#

The API is optional and client-side. Add the jar as compileOnly, then either register a source at runtime or declare the entrypoint so the HUD finds it at launch.

public final class MySource implements SlotSource {
    public String id() { return "mymod"; }
    public String label() { return "My Mod"; }
    public boolean available() { return true; }

    public void collect(Minecraft minecraft, Player player, boolean includeEmpty,
                        List<ApiSlot> out) {
        ItemStack stack = myEquippedStack(player);
        if (!stack.isEmpty() || includeEmpty) {
            out.add(new ApiSlot(id(), "charm", "Charm", "charm", 0, stack));
        }
    }
}
{
  "entrypoints": {
    "loadouttc:slot_source": ["com.example.mymod.MySlots"]
  }
}

Effects, ability timers, panel control and slot queries are documented in the API reference.

Notes#

  • Close Minecraft before replacing the jar; Fabric lazy-loads classes from the open file.
  • Hover tooltips are editor-only: in normal gameplay the cursor is grabbed.
  • Glass looks are layered translucency, not a framebuffer blur.
